## What's Mongodb?

MongoDB is a NoSQL database management system that stores data in a flexible, document-oriented format. Unlike traditional relational databases (RDBMS), which store data in tables with rows and columns, MongoDB stores data in documents (similar to JSON objects), which are grouped into collections.

![](https://github.com/julioalexp/MongoDB/blob/main/mongo2.jpg)

## Is Mongo for DS?

Yes, MongoDB can be used for data science, especially when working with unstructured or semi-structured data, as it offers flexibility and scalability. While it may not be as common as relational databases for traditional data science tasks, it can still be highly effective in certain contexts.

## Practical project using Mongodb

This task involves importing a CSV file into a database, specifying data types for each column. It focuses on exploring two collections, `tipo_venta` and `ventas_vendedor`, within the `ventas_inmobiliarias` document. The process includes analyzing the schema and using the Analyze feature to examine the collections. A query is then executed to retrieve the types of income in the real estate business, such as Rent or Sales.
